# Анализатор xml файлов

## Описание

Эта программа парсит XML-файл, содержащий описание классов и их атрибутов, и генерирует:
1. файл `config.xml` с преобразованной структурой классов;
2. файл `meta.json` с топологически отсортированными классами.

Файлы сохраняются в директорию `out`, которая, при отсутствии, создаётся.

В коде используются модули стандартной библиотеки: `json`, `os`, `re`, `sys`, `xml.etree.ElementTree`,
`collections.deque`, `xml.dom.minidom`

## Использование

Программа запускается из корня проекта без параметров. По умолчанию скрипт ищет входной XML-файл в
`test_files/test_input.xml`. При надобности путь к файлу можно поменять в коде программы.

## Обработка ошибок

Программа проверяет:
- Корректность XML-файла (`validate_xml`)
- Наличие корневого класса (ровно один `isRoot="true"`)
- Существование всех классов в `Aggregation`

При ошибках скрипт выводит сообщение и завершает работу.
